\# Calculator-CS



Aplicatie consola in C# care efectueaza cele 4 operatii: +, -, \*, /.

Impartirea la zero este verificata.



\## Cum se ruleaza

1\. Clonati repository-ul: git clone https://github.com/Cristina-csharp/Calculator-CS.git

2\. Intrati in folder: cd Calculator-CS

3\. Rulati comanda: dotnet run

4\. Pentru iesire scrieti x in loc de operatie.
